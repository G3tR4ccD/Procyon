# Procyon

A set of low-poly 3D fantasy weapons and shields, each marked with a raccoon-face emblem. Every piece comes in four color variants. I modeled all of it myself.

## What's inside

Each color set has six pieces:

| Piece | Notes |
| --- | --- |
| Small shield | Rounded, with the raccoon emblem |
| Large shield | Tall, with spikes along the top edge |
| Mace | Spiked head |
| Sword | Broad, leaf-shaped blade |
| Longsword | Long, straight blade |
| Dagger | Tapered blade with a crescent guard |

The four variants are **Wooden**, **Rust**, **Tempered**, and **Gilded**. The Tempered and Gilded sets add small colored gems, and the gold set swaps the shield faces to a warm orange.

That makes 24 models in total.

## Status

Right now this project holds models only. There are no scripts yet.

## What I practiced

- Low-poly modeling with clean, simple shapes.
- Reusing one design across several color variants.
- Bringing finished models into Unity.
